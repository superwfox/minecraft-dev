# 技能库

模型默认熟悉 Paper/Bukkit 的常用 API。需求用到额外的库或固定套路时，例如接入 WebSocket、对接某个前置插件、套用成熟的计分规则，可以在生成前挂载对应的 **Skill**。挂载后，这份资料会在规划和生成时提供给模型参考。

## 怎么挂载

1. 打开技能库页（顶部导航的 skill），或在对话页打开技能抽屉。
2. 技能以卡片形式排开，点击卡片查看能力说明、适用的核心和版本。
3. 点选卡片加入「已挂载」，拖动可以调整顺序，靠前的优先级更高。
4. 选择会保存在当前浏览器，下次打开还在。之后正常发起生成即可。

只挂这次真正用得上的技能。挂得太多会稀释上下文，反而可能让生成跑偏。

## 技能从哪里来

技能来自社区仓库 [superwfox/TAHAI-Skills](https://github.com/superwfox/TAHAI-Skills)，任何人都可以贡献。

一个技能由若干条目组成：

| 类型 | 作用 |
| --- | --- |
| gen（功能） | 带生成器的条目，指导模型生成对应的代码文件，例如某个封装类或对接层 |
| ref（资料） | 纯参考资料，例如 API 说明、用法约定、示例，只用于理解，不直接生成文件 |

## 贡献技能

1. 登录后，在技能库页的上传入口提交你的技能文件。
2. 服务端校验格式后，由机器人账号在 TAHAI-Skills 仓库自动创建 PR，并 @ 你的 GitHub 账号。
3. 维护者合并后，所有人都能挂载这个技能。

为防止刷 PR，每个用户 60 秒内只能上传一次。

<details>
<summary>了解细节：技能如何进入生成</summary>

发起生成时，前端把已挂载技能的 id 列表（`skillIds`）随 `POST /api/generate/task` 提交。服务端 `getSkillBundles` 按 id 拉取完整内容（KV 缓存 30 分钟）并存入任务状态，在结构规划和逐文件生成时注入上下文。技能可以声明 `coreTypes`、`mcVersions` 等元信息。

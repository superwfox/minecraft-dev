# 行为路径生成示例

以 Paper 1.21.4 家园插件为例：需求为“/sethome 设置家园，/home 返回家园，YAML 保存，进服提示家园数量”。

1. 提交需求并确认核心与版本，回答必要的需求澄清。
2. 模型通过树工具构造 Main 下并列的设置家园、返回家园和进服提示路径。每个步骤绑定命令、监听或管理文件，持久化逻辑复用同一实现。
3. 点击步骤原位查看职责、绑定文件和 Node contract；底部输入自然语言修正，例如“返回家园增加 5 秒冷却”，模型同步调整相关路径、文件及契约。
4. 确认结构并开始生成。实现文件按依赖顺序生成，多条路径共享的文件只生成一次，节点同步显示状态和契约核对结果。
5. 文件齐全后，模型沿每条需求路径静态审查实现，包括入口注册、条件、参数、分支、状态与结果。Pages 调度 GitHub Actions 完成真实 Maven 编译。
6. 路径静态审查和对应代码编译均通过，沿路线播放方块粒子并将虚线更新为实线。静态问题保留在路径结论中，编译通过不会抹掉问题。
7. 下载 JAR 和 Maven 源码 ZIP；源码包含 PROJECT_TREE.md，列出路径、步骤、绑定文件、契约和检查结论。在自己的服务器中完成游戏内实测。

刷新或断线后任务停在中断态，由用户手动继续；代码按需从服务端读取。文件齐全时，即使构建失败，也可以下载源码查看问题。

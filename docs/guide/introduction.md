# 项目介绍

踏海是一个在浏览器里生成 Minecraft 服务端插件的平台，入口是 [tahai.xyz](https://tahai.xyz) 对话页中间的对话框。你在对话框里用中文描述插件要做什么，平台负责拆解需求、写出完整的 Maven 工程、在云端编译，最后交给你可以直接放进服务器的 JAR。

## 适合谁

- **服主**：有明确的小功能需求，例如进服提示、简单命令、领地圈选、定时清理，但不想自己学 Java。
- **想改现有插件的人**：手上有一个插件 JAR，想加一点功能或修一处问题，可以[导入 JAR](/features/jar-import) 后用自然语言提修改。
- **插件开发者**：用它快速搭出框架和样板代码，下载源码后继续自己写。

## 它会做什么

1. **确认需求**：读取对话框里的文字、Markdown、代码块或导入的 JAR。核心、版本或关键行为没说清时才会追问，需求有歧义时给出几个选择题。详见[对话框](/guide/chatbox)。
2. **规划结构**：把需求拆成一条条行为路径，例如“玩家右键地面圈选”“命令指定坐标”，每一步对应要写的文件。你可以用一句话修正，满意后确认。详见[结构树与行为路径](/features/structure-tree)。
3. **生成与检查**：逐个文件生成代码，自动审查、返工和补缺，再沿每条路径检查实现是否完整。
4. **编译与修复**：在 GitHub Actions 上真实编译；编译失败时自动读取报错并修复，最多重试 3 次。详见[生成、检查与编译](/features/generation)。
5. **交付**：下载 JAR 和 Maven 源码 ZIP。工程会保存在浏览器里，之后可以继续修改或下载历史版本，见[工程历史](/features/project-history)。

## 支持范围

- 核心：Paper、Bukkit、Spigot、Forge、Fabric；不确定时选 Paper。
- 版本：MC 1.7 到 26.2，按版本自动选择 Java 8、11、17、21 或 25。
- 需要额外的库或对接前置插件时，可以先在[技能库](/features/skills)挂载对应技能。

## 费用与 Key

- 推荐填写自己的 [DeepSeek API Key](https://platform.deepseek.com/)。Key 只保存在当前浏览器，请求时临时传给服务端，不写入任务记录或数据库，也不扣平台余额。
- 每月免费额度已取消。原有充值余额继续保留，也可以充值使用平台模型（1 元 = 1 件，¥25 银徽，¥50 金徽）。
- 编译次数的上限对所有用户都有效。

## 局限

踏海擅长**功能明确、逻辑不太复杂**的插件。以下情况建议只用它生成框架，再由开发者完善：

- 复杂的经济、RPG、小游戏等系统；
- 需要接入数据库或深度对接其他插件；
- 对性能有严格要求。

“检查通过”只代表代码层面的静态审查和编译通过。插件在游戏里的实际表现，仍需要你在自己的服务器上测试。

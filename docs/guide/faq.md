# 常见问题

## 使用

**一定要先选核心和版本吗？**

不用。直接在对话框里写需求即可，顺手写上“Paper 1.21.4”这样的信息更好。只有描述里推断不出核心或版本时，才会弹出选择框。见[对话框](/guide/chatbox)。

**需求写得乱，要先整理吗？**

不用。登录后停顿几秒，平台会自动给出一份整理好的版本，点「应用格式」替换，不满意可以撤销，也可以不理会直接发送。

**哪些插件适合用它做？**

适合事件监听（进服、退服、聊天、破坏方块等）、简单命令（传送、给物品）、配置读写、定时任务和权限判断。复杂经济系统、RPG、小游戏或数据库集成，建议先用它生成框架，再找开发者完善。

**结构树里的虚线和实线是什么意思？**

虚线表示这条路径还没有通过检查。只有当这条路径的静态检查和对应代码的编译都通过后，才会变成实线。实线不代表已经在游戏里测试过。详见[结构树与行为路径](/features/structure-tree)。

**生成卡住或失败了怎么办？**

先从历史记录恢复工程，点击「继续任务」。如果最终仍然失败，反馈表单会自动弹出一次，报错和执行记录会自动附上，不需要你重新填写。见[问题反馈](/features/feedback)。

**插件效果不对，想改一下？**

在同一个工程里输入新的修改需求，例如“欢迎消息要带玩家名”。确认结构变更后，只有受影响的文件会被修改并重新编译，旧版本仍然可以下载。见[工程历史](/features/project-history)。

**能修改别人写的或者以前的插件吗？**

可以把 JAR 拖进对话框导入，还原成可修改的工程后再提需求。混淆过的插件或非 Java 编写的插件不保证能还原。见[导入 JAR](/features/jar-import)。

## 数据与费用

**我的工程保存在哪里？**

保存在当前浏览器的本地存储（IndexedDB）里，按 GitHub 账号区分。清理浏览器站点数据会删除这些工程，重要的工程请下载源码 ZIP 备份。

**额度怎么算？**

每月免费额度已取消，原有充值余额不会清零。填写自己的 DeepSeek Key 后，模型费用走你自己的 DeepSeek 账户，不扣平台余额；不填 Key 时按平台余额扣除（1 元 = 1 件）。

**我的 DeepSeek Key 安全吗？**

Key 只保存在当前浏览器。生成请求会临时带上 Key，服务端不会把它写入任务记录或数据库。

**生成的代码安全吗？**

代码由模型生成并经过自动审查。平台只会在 `plugin.yml` 的作者字段里追加 TAHAI 标记，不会改动代码逻辑。上线前仍建议在测试服先跑一遍。

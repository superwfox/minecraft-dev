# 快速开始

跟着这篇做出第一个插件。全程只需要浏览器，不用安装 Java 或任何开发环境。

## 准备：登录并配置 Key

1. 打开 [https://tahai.xyz](https://tahai.xyz)。
2. 点右上角「···」里的 **登录**，用 GitHub 账号授权。
3. 首次登录会弹出 Key 窗口，填入自己的 [DeepSeek API Key](https://platform.deepseek.com/)。Key 只保存在当前浏览器；不填时使用已有的充值余额。
4. 之后鼠标移到左上角头像，可以查看剩余额度，也可以重新管理 Key。

## 第一步：在对话框里描述需求

对话页中间的对话框是唯一的入口。用大白话写清楚**什么时候触发、做什么、能不能配置**，可以顺手写上核心和版本：

```
Paper 1.21.4。玩家进服后被踢出并提示正在维护，
另外支持用 /setNotice 命令修改踢出时的提示文字
```

| 这样说更准确 | 这样说太笼统 |
| --- | --- |
| 玩家**进服时**发送欢迎消息 | 做个好用的插件 |
| 玩家**右键告示牌时**传送到出生点 | 实现传送功能 |
| 支持用**命令**修改欢迎语 | 可以配置 |
| **只有 OP** 能用 /reload | 加点权限 |

功能多时可以用 Markdown 列表分条写，需要固定格式的配置可以贴代码块。停顿几秒后，平台会给出一份整理好的版本，点「应用格式」即可替换，不需要也可以直接发送。完整说明见[对话框](/guide/chatbox)。

## 第二步：按提示补充

发送后，平台只在需要时追问：

- 描述缺少关键内容时，列出“还需要补充”的要点；
- 没写核心或版本时，弹出选择框，不确定就选 Paper 和服务器实际运行的版本；
- 需求有歧义时，用几张卡片让你选择，看不懂的选默认项即可。

描述足够完整时，这些步骤都会跳过。

## 第三步：确认结构树

模型会把需求拆成结构树：顶部是插件主类，下面每一列是一条行为路径，每个节点是一个业务步骤，并绑定要写的文件。

- 点击节点可以原位查看职责、绑定文件和接口约定。
- 想调整时，在底部输入框用一句话说明，例如“返回家园增加 5 秒冷却”，然后点击「开始修改」。
- 满意后点击「确认结构并开始生成」。

结构树的读法见[结构树与行为路径](/features/structure-tree)。

## 第四步：等待生成和编译

确认后，页面依次显示文件生成、检查和云端编译的进度。整个过程通常需要几分钟，取决于文件和路径数量。

- 编译失败时会自动读取报错并修复，最多重试 3 次。
- 关闭页面或断网后，进度会保存在浏览器里。回来后从历史记录恢复，再点击「继续任务」。

## 第五步：下载并安装

1. 点击 **下载 JAR**，得到一个 ZIP，解压出 `.jar` 文件。
2. 放进服务器的 `plugins/` 目录，重启服务器。
3. 进游戏测试效果。

也可以下载 **源码 ZIP**，里面是完整的 Maven 工程和一份 `PROJECT_TREE.md`，记录了路径、文件和检查结论。
